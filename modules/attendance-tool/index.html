2. 上班 09:01–09:29 → 下班 18:31–18:59
3. 儲存格為灰色系（不限單一灰階，深淺灰皆判定），且為週六、週日 → 不填寫
4. 儲存格未反灰，且為週一至週五 → 填寫
每個工作日隨機套用規則 1 或規則 2，並在區間內隨機取分鐘，讓時間看起來自然。
若儲存格反灰狀態與星期六日不一致（例如平日被反灰、或週六日未反灰），會跳出視窗讓你逐筆確認是否要填寫。
產生前會顯示「本月出勤確認」：已有資料預設保留；時數假可快速選 1／2／4 小時或自訂，詳細時間與時數雙向連動並扣除 12:00～13:00 午休；備註寫入 H 欄。
